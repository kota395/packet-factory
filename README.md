# packet-factory

データセンター/ネットワークを題材にした、ブラウザで遊べるインクリメンタルゲーム。
小さな Web サービスを運営し、稼いだお金を投資してインフラとユーザーを育てていく。
GitHub Pages などの静的ホスティングだけで動く。

**遊ぶ: https://kota395.github.io/packet-factory/**

> ステータス: インクリメンタル版の最初のバージョン(LB / WEB / DB、静的・書き込みの 2 種類、投資 6 種)
>
> 技術選定とライセンス方針は [docs/tech-stack.md](docs/tech-stack.md) を参照。

## 遊び方

- ユーザー数 × 0.01 がリクエスト流量(rps)になり、捌けた分だけ収入になる
- **投資**で広告(市場規模の拡大)・収益化(単価アップ)・性能強化・新機能の解放ができる
- 捌ききれずエラーや遅延が増えるとユーザーが離脱する。詰まってきたら WEB や DB を増設する
- 同じ種類のノードは買うたびに 15% ずつ高くなる。維持費もかかる
- ページを閉じている間も、直前の収支の 50% を最大 8 時間分受け取れる
- 進行はブラウザに自動保存される。別の端末へはセーブメニューのセーブコードで移せる

### 操作

- 下のツールバーでノードを選び、空きマスをタップして配置する
- ノードはドラッグで空いているマスへ移動できる(接続はそのまま)
- 「接続」で接続元 → 接続先の順にタップしてつなぐ(同じ線をもう一度つなぐと解除)
- ノードの数字は「届いている量 / 捌ける上限」(rps)。バーが黄色・赤になったら増設や強化の合図
- 接続できる向き: NET → LB / WEB、LB → WEB / LB、WEB → DB
- 速度は一時停止 / 等速 / 2 倍 / 4 倍

### 進行の目安(バランス確認ボットの結果)

| 時間 | 出来事 |
| --- | --- |
| 1〜2 分 | 最初の広告・収益化 |
| 4 分前後 | ロードバランサー解放、WEB を増設していく |
| 13 分前後 | 会員機能(書き込み)解放、DB 設置で単価が上がる |
| 30 分以降 | 盤面が埋まり始める(次の要素を追加する余地) |

## 開発

```sh
npm install
npm run dev      # 開発サーバー
npm test         # シミュレーションのユニットテスト
npm run build    # 型チェック + dist/ へビルド(依存ライセンスの検査込み)
npm run preview  # ビルド結果の確認
npm run balance  # バランス確認ボット(BOT_MIN=20 などで時間指定)
```

調整値は `src/sim/config.ts`(ノード性能・ユーザー増減・放置収入)と
`src/sim/economy.ts`(解放・強化の価格と効果)にまとまっている。
変えたら `npm run balance` のログで節目の時刻を見比べる。

### GitHub Pages で公開する

1. リポジトリの Settings → Pages で Source を「GitHub Actions」にする(設定済み)
2. `main` に push すると、テスト・ビルドのあと自動で公開される

PR ではテストとビルドだけを実行する。

## コンセプト

工場ゲームの「ベルトコンベアと加工機」を「ネットワーク経路とサーバー群」に置き換え、
インクリメンタルゲームの「稼ぐ → 投資する → もっと稼ぐ」の成長ループと組み合わせたもの。

- 投資でユーザーを増やすほど流量が増え、インフラが追いつかないと離脱で頭打ちになる
- つまり「市場を広げる投資」と「捌く力への投資」のバランスが常に問われる
- 常に **スループット / レイテンシ / コスト** の 3 つがトレードオフになる

## 今後の候補

### コンポーネント

| ノード | 役割・特性 |
| --- | --- |
| キャッシュ | ヒット率で後段の負荷を削減。容量超過で追い出しが発生 |
| CDN | 静的リクエストを手前で返す |
| DB リードレプリカ | 読み込みを分散できるが、レプリケーション遅延がある |
| メッセージキュー | バーストを吸収するが、遅延は増える |
| WAF / ファイアウォール | 攻撃トラフィックを落とす(誤検知もある) |
| 上位機種 | 同じマスでより高性能なサーバー(盤面が埋まった後の伸びしろ) |

### リクエストの種類

- 🟢 API 読み込み: キャッシュが効くとは限らない
- 🟣 重いバッチ: キューに逃がすのが正解
- 🔴 攻撃・ボット: 通すと他のリクエストを巻き込む

### イベント・障害

- バズによるトラフィック急増、DDoS 攻撃
- サーバー故障(冗長化していないと全停止)、リージョン障害
- キャッシュ全消し(コールドスタート)
- 機器の EOL(古い機材が使えなくなり移行が必要)

### 進行

- 転生: 会社を売却してリセットし、永続ボーナスを得る
- 個人ブログ → EC サイト → SNS → 動画配信 → グローバルサービス のように事業を広げる
